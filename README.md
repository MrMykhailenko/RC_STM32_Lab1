# RC_STM32_Lab1


Реалізованоий функціонал:

В програмі є стан #define ExectutableProgramm 1

При стані 1 - спрацьовує простий blink, світлодіод 1 секунду горить, одну секунду вимкнений і так у нескінченному циклі

При стані 2 - реалізовано керування світлодіодом по натисненню кнопки. Кнопка натиснута - світлодіод горить, кнопка відпущена - світлодіод погас

При стані 3 - реалізовано керування маркером. Натиснув один раз кнопку - світлодіод запалюється, при повторному натисненні - світлодіод гасне.
